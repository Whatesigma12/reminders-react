# Напоминания React

Проект на React + Vite.

## Запуск

```bash
npm install
npm run dev
```

После запуска откройте адрес, который покажет Vite, например `http://localhost:5173`.

## Функции

- добавление напоминаний;
- пользовательская тема задачи;
- дата события;
- приоритет;
- подзадачи;
- отметка выполнения;
- поиск и фильтрация;
- сохранение в LocalStorage;
- компонентная структура внутри `App.jsx`: `TaskForm`, `Toolbar`, `Stats`, `TaskList`, `TaskItem`.
